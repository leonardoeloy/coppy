# Coppy logo

Asset: [`public/logo.png`](../public/logo.png). Used in the README, web app header, and browser tab icon. The PNG preserves the transparent background from the original generation.

Created with the built-in image generation tool. The emerald clipboard/document shapes and opposing arrows represent shared text and two-way file sync.

## Generation prompt

Create a polished, distinctive logo mark for Coppy, a friendly developer tool that shares clipboard text and syncs files between computers. Deliver ONE standalone square logo mark, on a genuinely transparent background with alpha. No wordmark, no letters, no text, no mockup. Design: two offset rounded document/clipboard silhouettes interlock to suggest a continuous two-way exchange and subtly form a lowercase c through negative space. Strong coherent silhouette legible as a small 32px app icon; generous thick geometric forms, carefully balanced rounded corners. Palette: vivid emerald green #10b981 and deeper teal #059669; clean flat solid fills, no gradients, no shadows, no glow, no 3D. Center the symbol, occupying about 85 percent of the canvas, minimal surrounding transparent padding. Contemporary precise open-source software identity, attractive on both white and almost-black surfaces. No enclosing white tile or fake checkerboard.
