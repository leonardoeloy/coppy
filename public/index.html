      Getting set up ＋

      Open a terminal in the folder you want to share, then run:

      .\coppy-windows-amd64.exe --peer SERVER_IP . chmod +x coppy-darwin-arm64 && ./coppy-darwin-arm64 --peer SERVER_IP .

      Use the matching filename for ARM64 Windows or Intel Mac. Replace . with another folder, or add -b before it to run in the background. The server already syncs its own folder. Deleted local files are restored from the shared copy.

      Desktop downloads include this server’s public certificate.
