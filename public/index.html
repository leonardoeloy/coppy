Shared files

Files sync to the folder selected by each connected desktop client.

    Download desktop sync

    Choose your computer, download the app, then run it in the folder you want to share.

    Download Windows x64 Download Windows ARM64 Download Mac Apple silicon Download Mac Intel

    Desktop binaries include this server’s public certificate.

    Download public CA certificate

    Run in PowerShell: .\coppy-windows-amd64.exe --peer SERVER_IP .

    Mac: chmod +x coppy-darwin-arm64 && ./coppy-darwin-arm64 --peer SERVER_IP .

    Runs in the foreground, syncing the current folder both ways every 3 seconds. Add -b before the folder to run in the background. Replace . with another folder to sync it. Run on both machines. Local deletions are restored from the server.
